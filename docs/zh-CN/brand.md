# codes：设计理念与标识

**codex no cli = codes**

[English version](../brand.md)

codes 的理念是让用户通过自托管的 Web 工作区使用 Codex，日常操作无需进入终端。会话、计划、审批、消息排队和代码变更审查，应当形成清晰、连续的浏览器工作流。

这里的 “no cli” 指使用体验。底层依然由 Codex CLI 及其 App Server 执行任务。

## 设计原则

- 通过布局、分组与明确状态解释操作流程，减少重复提示。
- 保留 Codex 原生任务、权限、审批与计划语义。
- 保持界面、架构和实现简单，复用组件与状态来源。
- 区分任务进度、待回答、队列状态和连接状态；未知执行结果先核对，再继续。
- 让人和智能体都能通过语义名称、键盘操作和可判断的状态完成任务。

这些原则指导后续开发；具体已实现能力以 README 和验收文档为准。
