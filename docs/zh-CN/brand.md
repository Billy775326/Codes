# Codes 设计理念与标识

[English](../brand.md)

**codex no cli = codes**

这句话描述日常使用方式。在自托管浏览器工作台里连接项目、会话、审批、队列与代码变更。实际任务由主机上的 Codex CLI 和 App Server 执行。

## 设计原则

- 按用途组织控件，用布局和状态表达下一步，必要时给出明确的恢复提示。
- 保留 Codex 原生任务、权限、审批和计划行为。
- 分别呈现任务、待处理问题、队列和连接状态。
- 保证控件名称、焦点和键盘操作可用，方便人和智能体操作。

[界面设计规范](../interface-design.md)记录了这些原则在工作台里的具体应用。

## 标识状态

采用项目所有者提供的 V3 标识。导航和登录页使用原始图标与字标，字标随界面前景色显示。浏览器 favicon 使用独立图标。
