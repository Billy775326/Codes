# codes

A self-hosted web workspace for Codex CLI on Linux, with an IDE-inspired interface.

## Status

Project initialization. A runnable application is not available yet.

## Planned scope

- Manage projects and conversations on a Linux host.
- Attach files and code selections as context.
- Follow streamed responses and tool activity.
- Review approvals and code changes.
- Use a desktop browser for development and a phone for progress checks and approvals.

## Technical direction

Use the [Codex App Server](https://learn.chatgpt.com/docs/app-server) to connect the web interface to Codex running on the host. The application will manage browser access and presentation while Codex handles execution and native conversation history.
